# Landslide-risk-predictor
A machine-learning web application that predicts landslide risk using environmental and geographical data.

## Features

- Predicts landslide risk using ML
- Interactive Streamlit interface
- Supports environmental input data
- Displays risk level and prediction confidence
- Easy to run and deploy
- Accuracy of model is 99%

## Technologies

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib

## Installation

```bash
https://github.com/Vishwas-verma2006/Landslide-risk-predictor.git
cd Landslide-risk-predictor
```

## Run the App

```bash
streamlit run landslide_risk.py
```

Open the displayed local URL in your browser.

## How It Works

1. Enter environmental conditions
2. Enter values in parameters like "Rainfall".
3. Click **Predict**.
5. View the predicted landslide-risk.
6. Click **Probablity**
7. View the probability of both category
